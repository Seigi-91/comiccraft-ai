# 视觉工作流验证

- 参考资产。手机宽度的真实项目页面锁定了多萝西、托托和木屋活门三个参考版本，绑定到第 6、7 格。
- 分镜草图。隔离 API 回归验证暂停、保存、越界校验、版本冲突与参考附图。浏览器夹具验证了子镜头和对白坐标编辑。
- 真实修订。只有第 6、7 格换图，其他六格沿用原画。共 5 次成功生图、13 次成功视觉调用。最终八格通过，最后一轮复用六格审核。
- 独立排字。移动气泡并保存约 1.9 秒，模型调用记录未增加，八张原画未变。
- 跨章资料。隔离回归验证同一小说的下一段可继承前章末镜与服装。未额外生成第二章实图。

初版整章的 12 次生图与 19 次文字／视觉调用只作为背景。两次任务的范围不同。本次复用了已有图片作为参考，未额外实跑全新参考候选。木屋参考的地面视野曾被带进空中镜头，重绘后通过。最新指令进一步区分结构参考和当前状态，仍需独立实图对照。


## 自动分页与场景记忆

- 用《我们得谈谈五十五号》同一批四格原画重新合成第一页，核对全宽主格、不等宽双格、画内对白和窄沟槽。[合成样张](../docs/images/fifty-five-paged-preview.jpg)
- 本地 API 和渲染回归覆盖自动排页、错误版式拒绝、旧版条漫切换、场景参考继承、版式保存冲突、裁切填框和气泡坐标往返。修改版式时沿用原画。
- 样张的分镜角色、构图焦点和避让区由人工标注。本轮验证合成及流程，尚未通过真实模型从原文重新生成完整章节。
