# 自动化效率回归

`tests/test_automatic_workflow.py`使用确定性假模型与测试PNG，验证调用次数、失效规则和真实进度数据结构。不是画质、真实耗时或供应商收费基准。

| 场景 | 实际测试观察 | 可得结论 |
|---|---|---|
| 三格，第三格首次失败 | 首次尝试索引0、1、2；恢复只尝试2，总序列`[0,1,2,2]`，前两格复用 | 在此合成场景，恢复避免了两次重复生图。完整重跑需再做0、1、2是流程推算，未冒充旧版本独立实测 |
| 四格审核不变 | 首次4次，重复审核0次新增调用 | 同一输入的通过结果可复用，不代表审核正确性得分提高 |
| 仅末格图片改变 | 只有该格新增1次审核，其他3格复用 | 指纹按实际依赖失效，未简单清空全部结果 |
| 人物参考图改变 | 所有4格重新审核 | 不会用旧身份条件下的通过结果跳过检查 |
| 旧人工待办切自动 | 原文字待办变superseded，不存在伪造response；流程自动走到保留的图片回填阶段 | 模式转换不再要求复制旧JSON；未通过转换偷偷切换尚为人工的图片模式 |

真实App Server生成验证、首次本人OAuth与全链路测试的范围另见 [连接说明](../docs/CODEX_CONNECTION.md) 与 [调研](../docs/AUTOMATION_RESEARCH_2026-11-02.md)。没有统计独立用户机器的安装成功率，没有宣称整体提速倍数或费用下降比例。
