六个分工 Agent

剧情、分镜、台词、生图、审核、排版，明确职责与结构化交接。

画面内气泡编辑

拖动位置、尺寸和尾尖，切换对白、独白与旁白。

局部蒙版精修

圈选失真区域、比较候选、确认采用，并保留原版。

素材生产工作台

设定快照、批次、参数候选对比与非破坏特效。
