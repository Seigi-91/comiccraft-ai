官方Codex自动连接

安装连接器并使用自己的ChatGPT登录，可自动返回文字与附图任务结果。API 模式也可选用。首次由本人登录并验证后启用；本机已实测文字、视觉与生图。逐格保存进度，恢复时只补未完成或已变化内容。

安装、实测与边界

从小说，改编成漫画

导入TXT/Markdown或粘贴正文，按片段设定改编方式与篇幅，先提取角色卡并审阅大纲，再审阅分镜草图与对白。可以锁定角色、场景和道具参考，按格绑定后开始绘制。原著与旧作品分开保存，支持回退；当前按片段逐章制作。

小说改编指南

专业知识与第一次创作

六个 Agent 配备 24 张原创知识卡，按任务检索导演分镜、对白、连续性与排版方法。每张卡提供来源定位、适用限制和原创正反例；生成任务冻结知识快照。项目提供有/无知识建议的对照记录入口，生成质量提升仍待实测。完整应用首页可导入六格可编辑示例，不发起模型调用，并检查本机环境。
