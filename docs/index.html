从小说，改编成漫画

导入TXT/Markdown或粘贴正文，按片段设定改编方式与篇幅，先审阅可编辑大纲，再衔接原有分镜、台词、绘画和气泡流程。原著与旧作品分开保存，支持回退；当前按片段逐章制作。

小说改编指南

专业知识与第一次创作

六个 Agent 配备 24 张原创知识卡，按任务检索导演分镜、对白、连续性与排版方法。每张卡提供来源定位、适用限制和原创正反例；生成任务冻结知识快照。可用本机 ChatGPT 手动完成有/无知识建议对照，生成质量提升仍待实测。完整应用首页可导入六格可编辑示例，不发起模型调用，并检查本机环境。
