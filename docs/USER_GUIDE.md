# 完整操作手册

## 1. 项目、角色与章节

创建项目，填写主题、故事灵感和画风。角色档案包含身份、性格、固定外貌、背景、关系、语言表达；参考图单独上传。服装是独立方案，选择“当前服装”并保存后影响新的创作与图片修订，旧稿不会自动换装。

为每章创建标题。点击生成后依次完成：剧情策划 → 分镜 → 台词 → 交接检查 → 生图 → 视觉审核 → 排版。每个回填任务包含实际使用的提示词、规则和参考图。图片审核必须附实际图片，不能只看描述。

## 2. 修改大纲、分镜、台词

通过标签页表单修改，可添加/删除/移动条目。保存前会提示受影响的下游内容：大纲影响分镜及后续，分镜影响台词及后续，台词编辑稿会触发后续重新制作。保存前自动留版本，之后点“继续任务”。

## 3. 气泡编辑

完成稿中点“拖动与编辑气泡”。选择分镜；拖顶部移动气泡，拖右下角缩放，点击文字编辑。紫色端点决定尾巴方向与长度；对白为尾巴，内心独白为圆点，旁白没有尾巴。可新增、删除、调整字号及类型。端点进到气泡内部时不画尾巴。

保存气泡直接重排，不重画原图。手动气泡不会为了避让其他气泡而自动改位置，避免破坏用户摆放。

“AI 识别留白并定位气泡”会请求实际视觉分析，返回脸、手、道具保护框和放置建议。越界、覆盖保护框或气泡交叠会被拒绝。ChatGPT 模式仍需附图回填；保护框可能漏检，最后必须预览。

## 4. 单格重画与局部精修

点击单格缩略图可要求重画。它会重新请求该格，其他格复用，再做审核排版。

若只改手指等局部，使用“圈选局部精修”：

1. 选择分镜，按住画面圈出区域，松开闭合；可多圈，支持撤销和清空。
2. 填写具体修改要求，创建精修任务。
3. 默认协作模式中，将原图、白色选区蒙版和提示词交给 ChatGPT。
4. 上传返回图作为候选；尺寸不符时明确报错，可许可同宽高比对齐。
5. 拖动对比滑块，检查结构和接缝。
6. “采用候选并更新成稿”才替换分镜；采用前留版本。

合成时只取蒙版内的候选像素，蒙版外保留原图。这个保证针对原始分镜像素；后续缩放、文字和额外特效属于成稿合成。模型质量和接缝需要人工检查，不能把像素保护等同于手部必然修好。

## 5. 生产工作台

### 每格快照与记录

生图请求记录冻结角色/服装、分镜、参考图、完整提示词及校验值、请求模型/参数、等待/完成/失败及图片结果。修改角色后不会倒改旧记录。已有图可补录当前设定，但“当前补录”不是历史生成证据。

### 批量章节

勾选章节并创建暂停批次，确认顺序后开始。同批次逐章执行，章内保持连续性依赖。等待回填时停在当前项，完成后推进。暂停/取消只停止后续项；当前项仍可完成。重启后批次暂停，避免意外继续消耗服务。失败项可以重试，已完成项不重做。

### 参数实验

选择现有分镜，输入两组风格及请求尺寸，创建实验批次，再开始。两个任务使用冻结参考图，候选并排显示，不自动改原图。比较后点击采用才能替换，源图已变化时拒绝覆盖。

当前桌面模式是提示词约束实验；没有 seed、采样步数、去噪强度控制。请求模型名不是对 ChatGPT 实际内部模型的证明。现有 HTTP 生图不支持参考图实验，因此明确拒绝，而不是丢掉参考图继续生成。

### 特效层

提供雨线、速度线、暖光、对比度。可开关、排序、设置强度和矩形范围；先预览后保存。原 PNG 不覆盖，图层在气泡之前合成。保存和版本回退保留图层状态；上游稿件变更后会清除失效图层。不会自动避开脸部。

## 6. 版本回退

版本包含整章的大纲、分镜、台词、图片、成稿及特效状态。可预览后回退；回退前再存一份当前状态。它不是仅回退一个输入框。未保存的草稿不属于版本；旧回填待办不能覆盖新的编辑稿。

## 7. 示例、视频与限制

`outputs/rain-night-light` 可直接查看 PNG/JPG，不需要安装。示例不会自动进入新建数据库。Release 提供 45 秒视频和可编辑 HyperFrames 工程；视频展示早期创作流程，后续编辑功能以当前源码和文档为准。视频音乐、字体等许可见工程内说明。

这是本地单用户应用，尚无完整身份验证、多人协作、分布式队列、完整向量 RAG 或印刷级多页排版。不要直接开放到公网。
