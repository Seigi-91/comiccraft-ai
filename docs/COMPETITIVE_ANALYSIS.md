调研日期：**2026-11-02（北京时间）**。仓库范围：公开 README、GitHub 元数据及本项目源码；未安装运行对方项目，未进行同模型、同预算的画质对照。因此下文是产品与工程比较，不能推导“本项目画质更好”或 Star 数与某个功能存在因果关系。第三方 README 是作者声明，不等于独立性能验证；未提及的能力不直接判定为没有。

## 本项目已有的优势

1. **编辑链条完整**：不是只给一张图。大纲、分镜、台词、图片、气泡及章节回退可以连起来修订。对应 `frontend/src/`、`app/api/routes/editing.py` 和版本相关服务。
2. **文字与图像连接解耦**：既能用 ChatGPT 手工交接，也能分别配置文字/视觉和图片的 OpenAI 兼容 API。适合没有本地 GPU、但愿意自行提供模型服务的创作者。不是零成本或全离线模型。
3. **确定性的局部保护**：精修候选通过原图和蒙版合成，未选区沿用原始分镜像素。该性质有自动化测试，比“请模型不要改变背景”的提示词承诺更可检验。气泡与特效最终合成仍可能改变显示，应区分原始分镜与最终成稿。
4. **中文漫画控制**：独立绘制台词，支持气泡位置、大小、类型和尾尖，不依赖图像模型准确画中文字；视觉保护框还能辅助避让，但可能漏检。
5. **过程可审阅**：角色设定、前格参考、请求记录和快照有助于定位问题；上游 skills 固定版本和许可证较明确。

这些是现有能力的归纳，不代表对所有同类项目有独占优势。

## 主要短板与影响

| 优先级 | 短板 | 对用户的影响 | 改进与验收 |
|---|---|---|---|
| P0 | 缺少直接可玩的公开入口 | 安装前无法判断编辑体验 | 本轮加入免安装气泡体验；明确是预生成素材，不冒充在线 AI |
| P0 | 真实模型兼容证据有限 | “OpenAI 兼容”仍可能因模型、尺寸或 multipart 差异失败 | 建立已验证服务矩阵，记录端点、模型、日期和生成/视觉/编辑结果；凭据有效后逐项测试 |
| P0 | 新手仍需安装 Python、Node 和字体 | 首次启动流失，难定位错误 | 下一步做环境诊断与导入示例向导；先在干净 Windows/Linux 验收，再提供容器镜像或安装包 |
| P1 | 一致性主要靠描述与参考图 | 换角度、多人、手部或服装可能漂移 | 角色参考图审批与锁定、逐格服装状态、身份/服装/道具/空间分项评测；不能只靠一个模型总分 |
| P1 | 无预算硬上限、重试成本统计不完整 | 大批任务可能超出预期费用 | 先记录服务实际返回的 usage；未知价格显示未知，加入每任务最大重试次数与预算门槛 |
| P1 | 批次为单进程调度 | 重启恢复、并发、撤销语义有限 | 引入持久任务租约、幂等键、重试边界；先加进程中断恢复测试 |
| P1 | 完整应用不支持公开多人服务 | 不能把 BYOK 等同于每用户密钥隔离 | 需要账户、权限、HTTPS、密钥存储隔离和配额才能开放公网；当前维持本机部署 |
| P2 | 国际入口及社区贡献路径薄弱 | 外部开发者看不懂、不知道从何贡献 | 本轮加入英文 README、Issue/PR 模板与可验收的路线图 |
| P2 | 分享与迁移能力不足 | 使用者难展示过程、难跨设备继续 | 后续做完整项目导入导出、可复现问题包、PDF/CBZ/竖屏导出与公开作品展示许可流程 |

## 建议定位

**可编辑、可回退、可追溯的漫画创作工作室。Bring your own models; keep control of the comic.**

优先面向愿意参与创作的个人作者、中文漫画工作流使用者和 Agent 开发者。暂不以“最强一致性模型”“全自动商业漫画”“免费无限生成”推广。差异化证据应是用户能操作的编辑器、可检查的修复对比和具体测试，而非 Agent 数量。
