# 生产控制：角色、一致性、请求次数与恢复

## 角色审批与草稿

角色档案未审批时，保持旧版行为：新任务使用当前保存资料。上传参考图并保存档案后，可以「审批当前档案并锁定」。系统保存名字、参考图及其哈希、角色模块和服装的不可变快照。

锁定时拒绝修改模块、参考图或删除角色。点击「解锁编辑草稿」后可以修改，但生成仍用旧审批版；再次审批后新任务或显式图片修订才使用新版。角色变更不自动迁移所有历史分镜，也不会自动重绘。生成状态保留资产版本与哈希；章节回退恢复当时的章节快照，不把全项目角色审批头一并回退。

当前服装选择属于角色档案；**尚未实现逐格服装版本时间线和批量迁移审批**。这些与完整参考图生成训练管线仍在路线图中。

## 六维一致性评测

在素材生产工作台选择「一致性与证据」。对每格检查：身份、服装、手部、道具、空间、气泡遮挡。0 表示严重错误，1 表示轻微问题，2 表示符合要求；看不清或未检查保留未知。

每个已知分数还须填写具体可见观察，不能只写“通过”。旧报告缺少逐项观察时视为证据不完整。系统显示已检查覆盖率和已检查项得分，只有覆盖率100%、无0分、总分至少80%时标为通过。它是**人工 rubric**，不会把模型自评分伪装成人工结论。保存时绑定每格原图、最终成稿与台词/特效状态指纹，变化后旧报告标为历史状态；评测气泡时应同时查看当前完整成稿。

固定六格案例见 `benchmarks/consistency-cases.json`：单人换角度、双人轴线、手与道具。它是测试定义，不是已完成的同预算模型排行榜。记录模型、日期、参考图、全部候选和已知 usage；未知费用不能填写0。

## 服务兼容验证

设置页可以分别验证文字 JSON、视觉输入、文生图、参考图和蒙版编辑。必须先勾选费用确认，再手动点击；不会在保存配置或打开页面时自动调用服务。每次最多一个模型调用，失败不自动重试。

记录保留日期、模型、协议结果和当前配置是否仍匹配。通过说明服务返回的 JSON 或图片格式可解析，不能证明图片语义、艺术质量或未来权限。没有有效 Key 时仍需由运行者进行真实验证。不要把本项目的模拟测试填写成厂商已实测支持。

## 持久请求保护与 usage

`MAX_MODEL_REQUESTS_PER_TASK` 默认96，可在本机设置页调整为1–1000。实际 API 路径在发起任务前预留一次，使用数据库条件更新控制上限；ChatGPT 人工回填不消耗 API 预留。

- 上限按生成任务 ID 生效，失败、网络错误或进程中断的预留不退还；恢复同一个任务不会清零。
- 明确创建新的修订任务或批次项目会有新的计数范围，因此它**不是全项目累计金额预算**。直接调用适配器等无任务上下文的操作拥有独立单次范围。
- 数值 usage 只保存供应商实际返回的字段，不推测缺失 token 数或单价。没有金额证据时 `currency_cost=null`。
- 预留数保守计数，验证失败或本地输入检查失败也可能占用一次；这不是财务账单。
- `GET /api/studio/usage/{task_id}` 查询该任务；工作台的证据区汇总章节任务，实验任务可以用其 task_id 单独查询。
- 增加上限之前先查看失败记录、已有调用和服务账单。当前不自动执行价格换算，也不提供按人民币/美元的硬预算。

## 单实例任务恢复

章节生成与实验 runner 新增数据库租约，默认120秒、每30秒续租。相同 task_id 在已有有效租约时不能重复进入；续租失败会取消当前 runner。退出时只由租约拥有者释放。过期租约可由下一次明确执行获取。

重启后：进行中的任务保留阶段快照并标为中断，运行批次暂停，未完成的 API 预留标为 interrupted。先查看已生成素材与外部账单，再点继续；未过期租约最多等待120秒。不会自动补发所有未知结果的请求。

**这仍是单实例应用，不支持多个 Web 服务进程同时操作同一数据库并声称分布式安全。** 外部 API 在连接断开时可能已经计费；即使有租约，也不能承诺跨服务恰好一次计费。真正的供应商幂等、回执查询、全局队列和金额预算还需要专门适配。

## 知识证据

「一致性与证据」也显示 agent 使用的知识卡 id、SHA-256、检索类型和阶段。完整说明见 [知识库](../knowledge/README.md)。修改知识不会改写历史生成记录；需要精确复现时保留相应 Git 提交、模型版本和参考图。


### 任务冻结与效果评估

新生成任务保存完整语料快照和任务 ID，同一任务暂停恢复继续使用原快照；新的显式任务才使用更新后的知识。检索记录包含卡片和来源的哈希、匹配词、依据类型、证据 ID 与阶段。复现仍依赖原模型、附件与模型随机性，知识哈希不能保证相同图片。

[资料台账](../knowledge/RESEARCH.md) 和 [检索回归](../benchmarks/KNOWLEDGE_EVALUATION.md) 不等同于真实生成质量证据。当前采用本机 ChatGPT 手动实验，真实输出与完整逐项评分尚待运行者填写。[协议](../benchmarks/CHATGPT_AB_PROTOCOL.md)。


## Codex调用计数

Codex自动调用也使用持久预留上限，但一次CLI执行可能包含多轮底层推理或工具使用；预留计数是适配器执行次数，不是精确底层调用数、金额或额度。只保存CLI实际数值usage，费用未知。文字/视觉实测通过不证明生图可用；v2.5已通过本机真实生图连接验证；任何失败仍不自动改走API。[连接隔离与限制](CODEX_CONNECTION.md)。


## 原生附件与断点复用

官方App Server原生生成事件与线程关联，图片只从该次有效生成附件读取；模型文字路径不作为图片来源。每格完成后保存任务进度；恢复时核对生成输入、提供方与参考图哈希，改变后重新生成。模型审核只复用此前通过且全部证据未变的记录，不能替代人工一致性评测。
