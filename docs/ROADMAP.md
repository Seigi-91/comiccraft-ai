以下条目保留完整验收范围，部分已实现不等于整项全部完成。当前优先补真实干净系统安装反馈和真实服务测试。

## P0：让新用户完成第一次创作

1. **环境诊断与设置自检**：检查 Python/Node、端口、中文字体、可写目录；逐项提示原因和解决办法，不打印密钥。连接诊断与真正的付费生成测试分开，由用户主动触发。验收：干净 Windows + Linux 各完成一次启动；无权限或无字体时提示可操作。
2. **完整应用导入示例**：一键导入独立的《雨夜留灯》项目，使用预生成图片，不调用模型；重复导入不覆盖已有项目。验收：可改一个气泡并导出、再回退；示例记录标注素材来源，不伪造历史生成参数。
3. **服务兼容矩阵**：完成文字 JSON、视觉输入、文生图、参考图和蒙版五项测试。验收：每项记录服务、模型、日期、请求类型、成功/失败证据；无真实凭据的项保留“未验证”。

## P1：让结果更稳定、成本更可控

4. **角色资产审批和版本锁定**：角色表、服装、左右标记分别锁定；已生成格不因角色编辑自动换身份。验收：场景换装与角色版本迁移均有明确确认和回退。
5. **一致性基准**：固定三组案例（单人换角度、双人交互、手持道具），每组 6 格；分别记录身份、服装、手部、道具、空间、气泡遮挡。验收：公开模型/提示词/预算与人工逐项评价；模型评分只作辅助。
6. **预算与重试边界**：显示已知 usage 与未知项；限制重试与并发；失败阶段可恢复。验收：超限时不再发新请求；中断恢复不重复计费请求（依赖服务幂等能力时明确标注）。
7. **持久队列**：批次任务租约、幂等、重启恢复、逐项取消。验收：杀进程、断网、返回 429/500 都有可复现恢复测试。

## P2：让作品更易迁移和传播

8. **项目包导入导出**：结构化脚本、角色、气泡、特效与素材，排除密钥和私人待办；校验路径与文件大小。验收：在新数据库恢复，渲染结果一致。
9. **原生 ComfyUI / 其他供应商适配**：基于能力声明选择协议，不把所有服务都叫兼容。验收：至少一条真实工作流、模型和输入约定可复现，并公开设备要求。
10. **多格式输出与分享卡**：PDF/CBZ、竖屏与社交预览。验收：中文文字不截断、缩略图仍可读、输出不泄露密钥或私人提示词。

暂不纳入近期承诺：公网多租户 SaaS、自动桌面 ChatGPT 控制、全套训练与 LoRA 管线。希望贡献以上项目，请先提出具体方案，选取一项有边界的 PR；不要在一个 PR 中同时重写编辑器、队列和数据库。
