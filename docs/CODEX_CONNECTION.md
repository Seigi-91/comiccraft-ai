# 官方 Codex 自动连接（ChatGPT 登录）

这是现有模型连接的新增选项，不替换 API 与人工回填。文字、视觉和图像都通过官方 CLI 的非交互命令运行，不操作 ChatGPT 聊天窗口，不读取、复制或导出其登录令牌。登录凭据由官方 CLI 自行管理。

官方依据：[非交互执行](https://learn.chatgpt.com/docs/non-interactive-mode)、[登录方式](https://learn.chatgpt.com/docs/auth?surface=cli)、[CLI 参数](https://learn.chatgpt.com/docs/cli/reference)、[图片能力](https://learn.chatgpt.com/docs/image-generation)。能力仍受版本、账号和执行环境限制，文档中的功能描述不能替代本机实测。

## 安装与首次启用

1. 启动本机完整 ComicCraft，打开「创作团队与设置」。安装完整网站时需要的 Node.js 20+ 也用于本连接器。
2. 在「官方 Codex 自动连接」下载安装/登录助手 ZIP，**先解压**，Windows 双击 `Install-Codex-Connector.cmd`。源码目录也自带此文件。macOS/Linux 使用 `bash scripts/install_codex.sh`。
3. 脚本在用户目录安装固定版官方 `@openai/codex@0.166.0`，运行官方登录流程；由本人在浏览器完成 ChatGPT 登录。不会把密钥发到项目维护者或GitHub。已有指定安装目录不自动覆盖升级。
4. 返回网站刷新连接器状态。这只检查安装、版本和登录状态，不发模型请求。
5. 在「文字与视觉模型连接」选择「官方 Codex · ChatGPT 登录自动生成」。Codex模型留空沿用CLI默认；只有确认支持的模型标识才填写。原 API 设置保留，可切换回去。此版本另用原创短文在网站中实测自动生成改编大纲，正确停在审阅处；这不是文学质量基准。
6. 在服务验证中确认消耗额度，分别验证文字、视觉及需要的图片能力。成功仅说明本次格式/能力检查，不代表所有创作质量达标。

程序优先寻找项目独立目录、用户连接器安装目录、PATH中的原生CLI，以及已安装桌面应用附带的CLI。管理员可在 `.env` 用 `CODEX_CLI_PATH` 指定原生可执行文件或官方 `codex.js`；网页不能提交任意运行命令。Windows不通过cmd拼接执行参数。

## 图片：独立选择，先验证

文字自动成功不等于生图成功。可以选择「Codex文字/视觉 + 图片API」或「Codex文字/视觉 + ChatGPT图片人工回填」。原有API与蒙版编辑接口仍保留。

图片下拉新增「官方 Codex · 内置生图（需实测）」。它只接受该次任务目录中真实生成、可解析的PNG结果；文字中声称成功、返回图片路径或占位图均不算成功。没有工具或没有文件时明确失败，不自动重试，不转用API或手工模式。参考图与蒙版也须分别验证。即使模型接受请求，像素尺寸、风格或编辑语义仍需实际检查。

**2026-11-02 本机实测：CLI 0.166.0 已用 ChatGPT 登录，文字 JSON 与附图识别通过；内置生图没有返回真实图片，未通过。** 旧版0.152.1在两种沙箱权限下同样未返回图片。当前不能宣称本机已打通自动漫画绘画。详见 [实测记录](../benchmarks/codex-connection-2026-11-02.json)。没有据此推断所有账号或所有版本都不支持生图。

## 自动执行边界

- 当前连接器使用 `codex exec`，每次新的隔离任务目录与临时会话；不加载用户config.toml与exec规则。
- 禁用Shell、插件、应用连接器、网页和子代理；文字/视觉模式同时禁用生图工具。图片模式仅启用内置生图，输出限制在本次任务目录。CLI/管理员的上层配置仍可能影响能力。
- 只把当前提示词及明确选择的参考图片交给模型，不把网站API密钥作为子进程环境转发。要求官方CLI的ChatGPT登录，检测到API-key登录不会偷偷改走API。
- `CODEX_TIMEOUT` 默认600秒（30–1800）；超时终止本次子进程树，不自动重试。失败或中断可能已经消耗额度。
- 每任务请求保护按**适配器调用次数**计数，Codex一次调用可能含多轮底层推理/工具，不能解释为一次底层模型请求或固定费用。只记录CLI实际返回的数值usage，不推算金额；金额未知。
- 长篇小说仍使用既有逐片段改编和审阅停顿点。模型自动返回大纲不等于忠实度已审查。
- 保存模式不清除历史待办。已有人工待办请先完成，或在明确的新任务中使用新连接；不会伪造已回填状态。

## 配置示例

```dotenv
AI_PROVIDER=codex_cli
CODEX_MODEL=
CODEX_TIMEOUT=600
# 未单独选择图片模式时默认仍人工回填；可显式使用已有图片API。
IMAGE_PROVIDER=chatgpt_desktop
IMAGE_EDIT_PROVIDER=chatgpt_desktop
```

安装位置与模型权限属于运行者本机，开源项目不打包账户凭据、ChatGPT会员、离线模型或免费额度。完整后端仍默认只在本机使用，不提供公网上的共享账号服务。
