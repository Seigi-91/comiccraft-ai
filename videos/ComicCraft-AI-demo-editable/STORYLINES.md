## C — A rainy-night short film inside a creative tool
Device: the comic itself explains the product. Form: six full-frame artwork beats interrupted twice by the exact source screen that holds their writing.
First two seconds: the kitten under the bench and “一声猫叫，让故事继续”. The viewer first feels the story, then discovers the website.
Beats: rain and kitten → writing workspace → rescue and shelter → agent sources → lamp and ending.
Look: art-led indigo/amber, dark UI as a brief contrast.
Sound: calm piano, a single transition accent, no narration.

A is selected because the request asks to demonstrate the website and include this exact comic. The user explicitly requested MP4 plus editable source, so production proceeds without a separate storyline stop.
