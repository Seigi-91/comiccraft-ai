# ComicCraft AI · 45 秒 HyperFrames 宣传片

`index.html` 是可编辑时间线，素材在 `assets/`。需要 Node.js 22+、FFmpeg 和可用的浏览器。Windows 使用 Microsoft YaHei，其他系统建议安装 Noto Sans CJK SC。

```sh
npm run preview
npm run check
npm run render -- --output comiccraft-promo.mp4
```

画面取自 ComicCraft AI 的实际功能截图与静态漫画演示。漫画是 qntm 在 SCP Wiki 发布的 [We Need To Talk About Fifty-Five](https://scp-wiki.wikidot.com/we-need-to-talk-about-fifty-five) 的中文改编。原作、改编及本宣传片按 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 发布。音乐署名见 [MUSIC-CREDITS](MUSIC-CREDITS.txt)。
